# SpokenFeeds

**Turn your RSS feeds and any URL into a personalized audio briefing — AI summaries read in your own cloned voice.**

SpokenFeeds fetches your RSS feeds and any web article, summarizes them with an AI model, then generates speech using your own voice (or a preset). The result is a daily audio briefing you can listen to in the web player or the iOS app.

## Reporting a Bug

1. Check [existing issues](https://github.com/DarkStarDS9/spokenfeeds-public/issues) to avoid duplicates.
2. Open a [Bug Report](https://github.com/DarkStarDS9/spokenfeeds-public/issues/new?template=bug_report.md) and fill in the template.
3. If the bug involves playback or connectivity, attach the output from **Settings → Debug Tape** in the app — it captures detailed diagnostics.

## Requesting a Feature

1. Check [existing issues](https://github.com/DarkStarDS9/spokenfeeds-public/issues) and [Discussions → Ideas](https://github.com/DarkStarDS9/spokenfeeds-public/discussions/categories/ideas) first.
